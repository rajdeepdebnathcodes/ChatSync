ABOUT CHATSYNC

Understand your conversations.

ChatSync is a WhatsApp conversation analytics and visualization system designed to turn exported chat data into meaningful insights.

THE IDEA

From raw messages to useful insights.

WhatsApp conversations contain patterns about participation, activity, language, emojis, links and media. ChatSync processes an exported chat file and presents these patterns through a clean, interactive web interface.

Instead of manually reading thousands of messages, users can explore their conversation through statistics, charts, search tools and dedicated explorers.

WHAT IT CAN DO

Explore every side of a conversation.

ChatSync combines analytics and exploration features in one platform.

01

Conversation Analytics

Get an overview of messages, participants, words, media, links and conversation activity.

02

Participant Analysis

Compare participants based on message count, word usage and overall contribution.

03

Activity Analysis

Discover the busiest days, hours and periods of activity in the conversation.

04

Text Analysis

Explore word frequency, total words, average message length and longest messages.

05

Message Search

Search the conversation using keywords, participants, message types and dates.

06

Media, Links & Emojis

Explore shared media, websites and emoji usage across the conversation.

TECHNOLOGY

Built with Python and web technologies.

Python Core application logic
Flask Web application framework
Pandas Data analysis and processing
NumPy Numerical operations
Regex WhatsApp message parsing
Matplotlib Data visualization
HTML & CSS User interface

PROJECT PURPOSE

Make conversation data easier to understand.

ChatSync demonstrates how Python programming, object-oriented programming, regular expressions, data processing and visualization can be combined to build a practical web application.
